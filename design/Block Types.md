| Tower       | ![[Pasted image 20261002120641.png\|114]] | Tower is the only Block Type that cannot be assigned to a unit.                                                                          |

All Block Types except for Tower can be assigned to a unit, and each of the available Block Types is assigned to a slot in the player's Team.

Non-boss enemies are generally generated with a random Block Type, and can have duplicate Block Types in the same Active Team as a result.
### Xenoblocks
Xenoblocks are malformed Blocks, and can appear when allies are Infected or when enemies use abilities to create them. All Blocks have two Xenoblock forms, though some forms are shared.
