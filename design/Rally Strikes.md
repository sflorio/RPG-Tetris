Rally Strikes are collaborative attacks performed by all active, non-Downed allies when a Line Block is used to clear four lines. Each ally can learn multiple Rally Strikes, but only one can be equipped at a time.
## Learning Rally Strikes

The most common way to learn Rally Strikes is by spending Mastery Points at a Campfire, though they can also be learned through Memory Scrolls.
## Rally Strikes List

| Rally Strike Name | Effect                             | Usable By |
| ----------------- | ---------------------------------- | --------- |
| Doublestep        | All allies gain Shield and Haste+. | Soldier   |
