In the beginning, the player can only use their psionic abilities to read simple minds. Throughout the game, player will discover Psionic Crystals that will grant them new Psionic Powers.

Player can read all out of combat NPC minds for extra dialogue or clues.

Use Ideas:
- Reads NPC mind that they want a specific food, get for them
- Read multiple NPC minds to find out their mood, ask only the good mood NPC
- Read gambler NPC mind to get the answer to the game (guess a number, 3 card monte, etc.)

## Psionic Powers List

| Power Name   | Effect                                                                                                                                                |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| HP Sight     | HP bars for enemies are now displayed in combat.                                                                                                      |
| TP Sight     | TP bars for enemies are now displayed in combat.                                                                                                      |
| Future Sight | Cast bars for enemies are now displayed in combat.                                                                                                    |
| Peek         | Technique "Peek" becomes available, allowing the player to read the minds of NPCs in combat, potentially displaying battle tips or story information. |
| Psychometry  | Interact option "Psychometry" becomes available on some game objects, allowing the player to view past events through the object.                     |
| Mindread     | Technique "Peek" becomes "Mindread" and now also reveals the loot the NPC carries.                                                                    |
| True Sight   | When selecting a target for a Technique, a Perfect Strike icon will be shown if the action would result in a Perfect Strike.                          |
| Third Eye    | The Board now shows the next Blocks for both allies and enemies.                                                                                      |
